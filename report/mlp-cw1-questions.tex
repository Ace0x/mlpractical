\newcommand{\questionSix} {
\youranswer{Question 6 - Explain how one could use a combination of L1 and L2 regularisation. Discuss any potential benefits of this approach. Present an equation for this combined loss function and explain all relevant variables and hyperparameters.
|| According to \citealt{Zhang2018}, combining L1 and L2 regularisation can leverage the strengths of both methods to improve model performance. This technique is often referred to as Elastic Net regularisation. The combined loss function can be expressed as:
\begin{equation}
    \mathcal{L} = \mathcal{L}_{\text{data}} + \lambda_1 \sum_{i} |w_i| + \lambda_2 \sum_{i} w_i^2
\end{equation}
where:
\begin{itemize}
    \item $\mathcal{L}$ is the total loss function.
    \item $\mathcal{L}_{\text{data}}$ is the original loss function (e.g., cross-entropy loss).
    \item $w_i$ represents the weights of the model.
    \item $\lambda_1$ is the hyperparameter controlling the strength of L1 regularisation, promoting sparsity in the model weights.
    \item $\lambda_2$ is the hyperparameter controlling the strength of L2 regularisation, encouraging smaller weight values and reducing overfitting.
\end{itemize}
The potential benefits of this approach include:
\begin{itemize}
    \item Sparsity: L1 regularisation can lead to sparse models by driving some weights to zero, effectively performing feature selection.
    \item Stability: L2 regularisation helps to stabilize the model by penalizing large weights, which can improve generalization.
    \item Flexibility: The combination allows for a balance between sparsity and stability, which can be tuned based on the specific dataset and task.
\end{itemize}
In our implementation, we can use a mixing parameter $\alpha$ to control the relative contributions of L1 and L2 regularisation:
\begin{equation}
    \mathcal{L} = \mathcal{L}_{\text{data}} + \lambda \left( \alpha \sum_{i} |w_i| + (1 - \alpha) \sum_{i} w_i^2 \right)
\end{equation}
where $\lambda$ is the overall regularisation strength, and $\alpha$ (ranging from 0 to 1) determines the balance between L1 and L2 penalties.
By controlling $\alpha$, we can adjust the model to prioritize either sparsity or stability, depending on the requirements of the task at hand.
}
}
